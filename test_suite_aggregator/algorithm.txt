1. Get a list of test results
2. Initiate an empty dictionary to store the aggregated test results
3. Loop over the test results:
    3.1. Get the component
    3.2. If there is no dictionary with the component as its key in the aggregated test results dictionary:
        3.2.1. Initiate a new dictionary with the component as its key,
            and its other values are:
                . The number of the times the component has been executed as total_executed
                . The number of successes as passed_count
                . The number of fails as failed_count
                . The success persentage as pass_persentage, and it's an integer calculated by:
                    (passed_count / total_executed) * 100
    3.3. Increase total_executed by 1
    3.4. If the component's status is "PASS":
        3.4.1. Increase passed_count by 1
    3.5. If the component's status is "FAIL":
        3.5.1. Increase failed_count by 1
    3.6. pass_persentage is calculated by component's total_executed / component's passed_count * 100

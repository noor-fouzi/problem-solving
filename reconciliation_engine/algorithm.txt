Inventory Reconciliation Engine

1. Get a list of barcode scans and digital ledger balances
2. Initiate an empty dictionary to hold the inventory reconciliation
3. Initiate an empty dictionary to  store the look-up dictionary
4. Loop over the digital ledger balances:
    4.1. Unpack each tuble
    4.2. If its SKU number is valid:
        4.2.1. Turn the tuple into a dictionary
        4.2.2. Add the new dictionary to the look-up dictionary

5. Initiate an empty set to store the SKU numbers
6. Loop over the barcode scans:
    6.1. Get the SKU number of each scan
    6.2. If the SKU number is valid:
        6.2.1. Add the SKU number to the set
        6.2.2. If it exists in lookup:
            6.2.2.1. Calculate its difference 
            6.2.2.2. If the difference is not 0:
                6.2.2.2.1. Initiate a dictionary with a key sku number, and its value:
                    . The item's name from the barcode scan as name
                    . The calculated difference
        6.2.3. If it doesn't exist:
            6.2.3.1. Initiate a dictionary with a key sku number, and its value:
                . The item's name from the barcode scan as name
                . Set "MISSING_FROM_LEDGER" as difference

7. Loop over the lookup dictionary:
    7.1. If the item is not in the SKU numbers set:
        7.1.1. Initiate a dictionary with a key sku number, and its value:
                . Set "Unknown Product" as name
                . Set "MISSING_FROM_PHYSICAL" as difference


Tuple to Dictionary

1. Get a tuple of ledger
2. Unpack it into: SKU number and count
3. Initiate adictionary with a key SKU number,
    and its value is the count as 'ledger_count'


SKU Validator

1. Get an SKU number
2. Compate it with the regular expression : r"^SKU-[0-9]+$"

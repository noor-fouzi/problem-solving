Gateway Rate-Limiter Log

1. Get a list of gateway logs
2. Initialize a dictionary to hold the output - the IPs that exceeded an endpoint's limit - exceeded_limits
3. Initialize a dictionary to hold the endpoints hit by an IP and the number of hit_endpoints - endpoints_count
4. Initialize a set to hold the whitelist
5. Loop over the endpoints_count:
    5.1. Loop over the endpoints:
        5.1.1. If the endpoint is within the whitelist:
            5.1.1.1. Get its count
            5.1.1.2. If the count exceeds the limit:
                5.1.1.2.1. If the IP is not in the exceeded_limits dictionary:
                    5.1.1.2.1.1. Initialize a dictionary with the IP as its key,
                        and its value is an empty list
                    5.1.1.2.1.2. Initialize a dictionary with the following structure:
                        . The endpoint as offending_endpoint
                        . The count as the total_hits
                        . The limit as the allowed_limit                   
                        


IPs list

1. Get a dictionary of gateway logs
2. Initialize an empty list to hold the IPs
3. Loop over the logs:
    3.1. Add the IP of the log to the IPs list


IP's Hit Endpoints

1. Get a list of gateways 
2. Initialize an empty dictionary to hold the hit endpoints counts - endpoints_count
3. Loop over the logs:
    3.1. Get the IP
    3.2. Initialize an empty dictionary to hold the endpoints hit by the current IP,
        with the IP as its key - hit_endpoints
    3.3. If a dictionary with the key IP is not in the endpoints_count dictionary:
        3.3.1. Add it
    3.4. Get the endpoint 
    3.5. If the endpoint is not in the hit_endpoints dictionary:
        3.5.1. Add it as key, with initial value 0 as its count
    3.6. Increase the endpoints count by 1


Dictionary to Set
1. Get a dictionary
2. Initialize an empty set to hold the keys
3. Loop over the dictionary:
    3.1. Add its keys to the set one by one
